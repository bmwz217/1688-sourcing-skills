# Listing 撰写与竞品调研

用于已存在商品的 Listing 撰写、重写或关键词优化。以已有选品表、目录及用户指明的 SKU 为准。直接沿用已有父 SKU，无内部 SKU 时用现有货号或来源编号对账。若选择表与目录不一致，按用户指定范围交付并记录差异。本技能从核对已有商品开始。

## 按产品选择事实核对方式

- **背包、斜挎包、托特包**：读 [包袋工作流](references/bags.md)。保留原有上架图、颜色核对、严格竞品样本、亮点和中英交付方式。默认完成一款父体后等待确认，用户指定批量或连续处理时直接覆盖指定范围。
- **圣诞和家居装饰品**：读取已有选品表、采购链接、商品信息 JSON、产品文本和本地 SKU、详情或上架图，使用 [关键词研究与写作](references/keyword-research.md) 的事实、套装与变体规则。已有批量范围时按该范围交付。商品和父 SKU 沿用现有资料。这一入口不启动选品、利润测算或目录清理。
- 仅改写现有字段时，保留其余原文并核对新旧文案之间的事实及后台词冲突。保留原版或原文对照。

## 研究与写稿

1. 核对产品类型、材质、造型、件数、尺寸、配件和变体差异。父 SKU 共用稿仅采用全部目标子款适用的事实。同一父 SKU 的各子款共用一条稿，分组或关键事实未证实时记录缺口。
2. 默认用 ego-browser 调研 Amazon.com。先读 ego-browser 技能并运行 `ego-browser skill`，再按 [浏览器并发与恢复](references/browser-research.md) 执行。用户指定 Amazon 搜索 API 时，使用相应 API 技能，说明该来源能支持的证据类型。只按用户允许的来源补查缺项。
3. 按 [关键词研究与写作](references/keyword-research.md) 逐款预算最多三个不同核心词。记录真实的搜索联想、自然卡片、广告和对标详情，按证据核对购物意图。必须从 Amazon 竞品证据中逐款提取匹配词，并记录采用词的来源和写入字段。复用同类样本时说明与本款的匹配理由。
4. 写稿前核对适用站点和当前字段、类目规则。逐款写英中标题、五点、描述、英文后台词及适用的商品亮点。新写或改写的英文字段必须达到已核实适用上限的 80%，具体按字段校验规则执行。使用 [字段校验](references/validation.md) 与随附脚本。产品事实、来源、类目和变体须人工复核。
5. 默认交付一份 Excel 总表，每个父 SKU 恰一行，及各父 SKU 一份 `listing.txt`。每个字段中文在上、英文在下，五点逐条对应。后台搜索词提供可直接复制的英文。Excel 和 TXT 使用同一份最终文案。按用户明确指定的格式和位置交付。把逐款状态、缺口、逐词与搜索证据集中放入独立的研究记录。商品资料与关键词证据不足时仍交付可核实的草稿，标注受影响的字段。发布属于单独任务。
