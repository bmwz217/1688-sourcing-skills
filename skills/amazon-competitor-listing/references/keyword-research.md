# Amazon 关键词研究与写作

## 1. 事实和搜索意图

以父 SKU 对应的原图、资料与采购记录为依据。包袋按 [上架图规则](bags.md) 核；圣诞和家居装饰品读取本地的商品信息 JSON、产品介绍、对应款 SKU 原图和详情图，必要时复核用户已有上架资料。将实际可采购款和选品表明确纳入的款对应起来。选中范围不明时记录缺口。根据各款原图逐一核实品类、主题、造型、材质、件数、尺寸、配色、配件与可证用途。区别商品与拍摄道具、商品尺寸与包材尺寸、单件和套装。有冲突的属性只在核实后使用。记录本地图片、文件或 URL 和对应子款。

共用稿只写所有目标子款共同适用的事实。子款专属颜色、图案、尺寸、配置和件数可放在对应规格栏，逐项核对资料及类目允许的变体主题。适用范围不能确认时记录缺口，保留共用事实草稿。选购单件或所选套装时应明确购买口径。

从事实生成品类、主题、特征、场景和同义候选。自拟词和搜索联想分别留证。先移除会把买家带向另一类商品的词，例如独立摆件、挂式 ornament、微缩套装分别对应不同形态。排除竞品品牌、型号、不符材质、功能与促销宣称。

## 2. 收集 Amazon 证据

1. 记录站点、实际配送邮编、观察日期、时区与来源。邮编无法验证时记未知。每款最多提交 **3 个不同核心词**，先以准确品类和特征检索，只有需要区分意图或候选不足时补词。联想观察、同一词分页及查看详情不占用新核心词。复用已证实的同站查询和候选时记录来源与适用性。
2. 网页中观察并保存真实出现的联想原文及所输前缀。提交后确认实际结果 URL 的 `k`、搜索框和结果区均与目标查询对应，确认卡片已更新。发生自动改词、重定向或旧卡片残留时分别记录，只有实际落到且内容匹配的查询可获得结果证据。使用指定 API 则记录实际请求词、可用返回字段和顺序。API 缺失联想、广告状态或展示顺序时按字段缺项，不以 API 列表替作页面观察。
3. 核对每词展示顺序的 **前 20 张商品卡片**，不足按实际数量。记录位置、ASIN、标题、链接、自然/广告/无法判别。以 ASIN 去重计数，保存原始位置。按商品形态、套装口径、题材及用途标记自然结果为直接同类、近似或不匹配，分别保留数量。广告单列。位置反映本次页面展示。
4. 打开每款 **3–5 个**最接近的详情核实 ASIN、实际标题、图像、规格和件数，记录观察到的词、适用理由及直达链接。商品形态和购物意图相近时可共享约 **10–15 个相关 ASIN** 的候选池，各款仍独立匹配对应证据，重复用到的已核实详情可引用。颜色变体不能充作多个独立竞品。样本不足记录实际卡片数、可比数、详情核实数及缺口。
5. 证据类型逐条分开，包含实际联想、自然卡片、广告卡片、竞品详情、授权报告、商品事实和自拟词。优先采用事实相符且有多类证据支持的词。单一来源、近似证据或查询失败时说明依据和限制。公开联想顺序、广告位、结果数、词频、评论和近期购买标识无法推算搜索量、销量或转化率。没有授权指标时写“搜索量未知”。

可选使用用户已提供或明确授权读取的 Brand Analytics、Search Query Performance 或 Amazon Ads 搜索词报告。记录站点、报告、指标名称、日期区间以及 ASIN 或广告范围。只有报告明确列出的指标能支持对应判断。CPC、ACoS 只留投放记录，禁止进入 Listing 或替代自然证据。写作不读取未授权账户数据且不修改广告。

## 3. 按字段写作

- **标题**。尽早写能准确表达实物形态的词组，有真实的 Amazon 搜索或详情证据时优先采用。结合本款已核实的主题、规格、材质或数量形成可读标题。每个主词的产品证据、Amazon 证据及采用理由都可追溯。核心形态或意图没有可靠证据时发布前需补核，当前稿标为草稿。
- **商品亮点**。包袋继续按 [包袋工作流](bags.md) 提供。家居品按用户要求或类目适用字段提供。用已证实的属性或相关长尾补充标题。
- **五点与描述**。每点说明一个不同且已核实的事实或购买决策信息。文案读起来应是自然美式英文，按真实商品组织，不照抄竞品句子，避免五点只换商品名套模板。描述写实物、使用或陈列方法及必要规格。有实用价值时加入相关长尾。
- **后台搜索词**。选择未被前台覆盖的相关同义词、合理写法或补充意图词。按词去重，并检查与英文标题、亮点、五点、描述的重合。删除品牌、ASIN、促销、无关词及填字词。按当前规则测 UTF-8 字节。
- 中文对照保持同样的事实、尺寸量纲、件数和变体适用范围。使用美制单位时核对从公制换算及舍入。未知且不影响购买理解的属性可以省略。

## 4. 研究交付与质量门槛

Listing Excel 与 TXT 只承载可复制的字段。另交付独立研究表或记录，包含逐款状态、事实依据、未核验的字段和下一项所需证据。证据缺失时用已核实事实交草稿。按字段修改时保留原稿或原文对照，并明确哪些字段发生修改。

逐词记录内部 SKU、适用子款、英文词组、目标字段、采用或舍弃、理由、证据类型、原始查询或建议原文、匹配度、站点、配送邮编、观察日期、ASIN/直达链接或本地依据、搜索量口径。保存查询、前 20 卡片观察和详情入口，复用结果时也应可追溯。关键资料、主词意图或当前字段规则缺证时标明受影响项。交付前逐父 SKU 校对范围、变体、英中对应、样本和词位，并验证字段长度。按用户指定范围复核，可持续处理其余已有证据的商品。
