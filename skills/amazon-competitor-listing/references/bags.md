# 包袋工作流

## 产品范围与资料

用指定或对话已知的产品根目录。仅当范围与路径仍然找不到时询问。先枚举实际存在的父 SKU 目录，再定位 `产品上架图`。支持 `父体/产品上架图/颜色` 和 `父体/颜色/产品上架图`。编号断续时仍按实际目录处理。识品图片限该文件夹及其子目录。若有 `商品信息.json`，读取非空 `title` 辅助识品。某已存在父 SKU 缺少上架图时列出具体 SKU，询问用户补齐、提供正确目录或跳过。

逐父体先抽查一个颜色的足量上架图，记录所见结构、图中文字规格、采购标题与冲突。核对其他颜色结构图后才生成共用稿。肩带、背法、口袋、五金、容量、设备适配、真皮、vegan、防水或防盗宣称须有图示或用户确认。差异无法用一条共用稿准确覆盖时，记录并等待用户确认分组。共用标题省略具体颜色、颜色占位和“多色可选”。其他字段可使用有依据的颜色资料，按件数真实描述。

## 调研与样本

逐父 SKU 建立候选和结果。提炼最多三个精准美式英文核心词，覆盖品类、已确认特征及适用场景或人群，每种购物意图用一个词组。颜色变化可共用父体调研。不同造型、结构、功能或尺寸先核实父体分组。按共用研究指南记录每个词前 20 张卡片。候选不足时可看相同查询第二页，第二页候选另记页码，不计入前 20 样本，同一父 SKU 最多三个查询。

优先合并去重后筛选 3–5 个接近的独立竞品，再按 10–200 条评论（含边界）识别严格对标样本。同等匹配时优先自然结果和实际显示近期购买标识的商品。记录真实评论数及变体共享评论情况，评论未知或超范围的候选只作补充。复用详情时逐款核对相关性和差异，独立记录本款支持的 ASIN。样本不足时留实际严格样本数和缺口。

## 文案与原有交付

保留商品名称、商品亮点、五点、产品描述及后台词。包袋英文标题采用原有 60–75 字符交付范围，含空格和标点。平台及类目如有更严格限制，以可核实的适用规则为准，冲突时标注原因。英文亮点采用 100–125 字符的包袋交付格式，当前类目有更严格限制时以类目为准。无独立亮点字段时保留为文案交付项。现有仅标题改写继续保留旧亮点，改动亮点才使用完整检查。

每条五点根据本款选择一个不同的买家关注点，以简短卖点短语开头。适用类目允许时沿用大写短语格式，如 `UPPERCASE PHRASE: Details`。规则限制此格式时采用正常大小写。避免装饰符号或套模板凑点。描述可包含已核实的共用规格和日常搭配。后台词采用 [字段校验](validation.md) 的格式，235–249 UTF-8 字节可作为相关词充足时的写作目标。省略重复及牵强的词。

默认每款父体交付后等用户确认；用户指定连续处理或批量时持续执行，续做复用已完成记录。Excel 总表放产品根目录，每父体一行，颜色或子 SKU 汇总于同一行。同步将同一份中文在上、英文在下的文案保存为该父目录的 `listing.txt`。用独立研究记录保存政策、竞品、词证与逐款状态。若用户另要竞品报告，单独交付。
