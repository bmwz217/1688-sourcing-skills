1688 产品图片下载工具——调用说明
================================

脚本文件：1688产品图片下载.pyw


一、界面方式运行
----------------

直接双击“1688产品图片下载.pyw”，或在命令行中不带任何参数运行：

py -3 "1688产品图片下载.pyw"

程序会打开桌面界面。在界面中填写 1688 产品链接、选择保存根目录，然后点击“开始下载”。


二、命令行自动运行
------------------

命令行模式必须提交两个基本参数：

1. 1688 产品链接
2. 保存图片的文件夹名称或完整路径


方式 1：使用位置参数

py -3 "1688产品图片下载.pyw" "1688产品链接" "保存文件夹"

示例：

py -3 "1688产品图片下载.pyw" "https://detail.1688.com/offer/123456789.html" "商品A"


方式 2：使用具名参数

py -3 "1688产品图片下载.pyw" --url "1688产品链接" --folder "保存文件夹"

示例：

py -3 "1688产品图片下载.pyw" --url "https://detail.1688.com/offer/123456789.html" --folder "D:\产品图片\商品A"

也可以使用中文参数名：

py -3 "1688产品图片下载.pyw" --链接 "https://detail.1688.com/offer/123456789.html" --保存文件夹 "商品A"


三、保存文件夹说明
------------------

如果提交的是相对文件夹名称，例如：

"商品A"

图片将保存到：

脚本所在目录\下载结果\商品A

如果提交的是绝对路径，例如：

"D:\产品图片\商品A"

图片将直接保存到该目录。

命令行模式下，指定目录内会建立以下子目录：

sku             保存 SKU 图片
产品详情页      保存产品详情图片
产品文本介绍.txt  按顺序保存 #productPackInfo（包装信息）和 #description（商品详情）节点中的网页文本，兼容开放 Shadow DOM；遇到“平台活动下价格”后截断
商品信息.json     保存商品链接、标题、已售原文、商品起批量、国内运费和逐款名称、采购价、库存

“产品文本介绍.txt”与 sku、产品详情页位于同一级目录。详情图片中的文字不属于网页文本，不会写入该文件。

“商品信息.json”也位于商品目录。title 为产品标题，sold_text 为“已售40+个”等页面原文。
minimum_order_quantity、minimum_order_unit、minimum_order_text 分别保存主价格区明确显示的商品起批数量、单位和原文，例如 1、支、1支起批。
domestic_shipping 保存运费原文、人民币金额（amount_cny）及是否为起价（is_starting_price）。
skus 按页面顺序保存每款名称（name）、采购价（purchase_price_cny）和库存（stock），同时保留价格与库存原文。
字段值为 null 表示页面没有给出可明确读取的值。skus 为 [] 表示没有读到规格。页面起价只能用于成本估算。


四、可选参数
------------

--threads、--线程数
    并发下载数量，允许范围为 1～32，默认值为 8。

--retries、--重试次数
    单张图片下载失败后的尝试次数，允许范围为 1～10，默认值为 3。

示例：使用 4 个并发任务，每张图片最多尝试 2 次：

py -3 "1688产品图片下载.pyw" --url "https://detail.1688.com/offer/123456789.html" --folder "商品A" --threads 4 --retries 2


五、查看完整帮助
----------------

py -3 "1688产品图片下载.pyw" --help


六、运行注意事项
----------------

1. 首次运行时，程序会启动专用 Chrome。请在该浏览器中登录 1688，登录状态会保存在脚本目录下的“浏览器用户数据”文件夹中。

2. 下载过程中如果遇到登录、验证码或真人验证，请在打开的 Chrome 中完成验证。

3. 界面模式会弹出提示框，完成验证后点击“确定”继续。

4. 命令行模式会在窗口中提示，完成验证后回到命令行窗口并按回车继续。

5. 在其他目录调用脚本时，请使用脚本的完整路径，例如：

py -3 "E:\我的文档\背包亚马逊设计图\1688产品图下载\1688产品图片下载.pyw" "https://detail.1688.com/offer/123456789.html" "商品A"

6. 命令执行完毕时，退出代码 0 表示正常完成，退出代码 1 表示运行失败，退出代码 130 表示用户中断。


七、下载后自动清理详情图
------------------------

下载器在每款结束后本地运行 RapidOCR 和图片哈希比对。已确认的定制流程图、包含“店铺推荐”或“定制”任一词的详情图，以及同一详情页目录内的重复图，将移入 Windows 回收站。重复组保留排序最前的有效图。清理只作用于本次新下载的“产品详情页”图片。

本机的 OCR 环境默认使用 Python 3.12 的独立依赖目录。新机器可运行：

py -3.12 -m pip install --target "%LOCALAPPDATA%\Codex\1688-image-downloader\ocr-py312" -r "详情图清理依赖.txt"

若报告 ONNX Runtime DLL 缺失，请安装 Microsoft Visual C++ x64 Redistributable。依赖不可用时，下载器会报告已下载但尚未清理。

用户明确要求清理已有详情图时，在 PowerShell 或命令提示符执行下列两步。ROOT 为商品根目录或单个“产品详情页”目录，REPORT 为该次任务的本地报告绝对路径：

py -3.12 "详情图清理.py" "ROOT" --report "REPORT"
py -3.12 "详情图清理.py" "ROOT" --apply-report "REPORT"

只有人工确认是定制流程图后，才使用下列命令加入模板：

py -3.12 "详情图清理.py" --teach-flow "图片绝对路径"
