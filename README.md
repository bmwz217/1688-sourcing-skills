# 1688 选品技能

这是内部技能源仓库，提供一个可安装的 Codex 插件，包含圣诞与家居装饰选品流程、配套下载器、脚本和利润表模板。

## 更新

修改本仓库中的技能文件并提交即可维护统一版本。若已在 ChatGPT 工作区导入此仓库的插件市场，由管理员同步后，成员即可获得更新。

## 运行依赖

- 选品流程调用 `$ego-browser`，需在使用环境中单独提供该浏览器工具。
- 1688 下载器在本机运行，需要 Windows、Python 和 Edge；首次运行会在下载器脚本旁创建“浏览器用户数据”目录，供使用者自行登录 1688。
- 登录数据和下载结果不属于仓库内容，已通过 `.gitignore` 排除。请勿提交这些目录。
- 下载器的 Python 依赖见其 `scripts/requirements.txt` 和 `scripts/详情图清理依赖.txt`。

本仓库不包含任何浏览器登录资料。
